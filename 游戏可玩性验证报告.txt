一、核心流程验证
----------------

1. 发牌阶段 ✓
   - 庄家起手14张牌（已修复）
   - 其他玩家起手13张牌
   - 庄家不需要摸牌，直接出牌
   - 设置lastAction为"DEAL"标记发牌完成
   
   代码位置：Game.java dealInitialHands() 第174-198行

2. 庄家出牌 ✓
   - 庄家有14张牌可以出牌
   - 出牌后变为13张
   - 触发反应系统
   
   代码位置：Game.java discardTile() 第250-291行
   关键检查：hand.size() != 14 && !("DEAL".equals(lastAction) && getPlayerSeat(playerId) == dealer)

3. 其他玩家摸牌出牌 ✓
   - 非庄家玩家需要先摸牌（13→14张）
   - 摸牌后可以出牌（14→13张）
   - 出牌后触发反应系统

4. 反应系统 ✓
   - 出牌后检查其他3位玩家
   - 按逆时针顺序：下家、对家、上家
   - 只有下家可以吃牌
   - 胡>杠>碰>吃的优先级

5. 回合推进 ✓
   - 无人反应：推进到出牌者的下家
   - 有人碰/吃/杠：执行者成为当前玩家，需要摸牌
   - 有人胡牌：游戏结束

二、关键修复
------------

修复1：庄家起手14张
  问题：所有玩家都是13张，庄家无法直接出牌
  修复：dealer座位的玩家发14张，其他13张
  影响：dealInitialHands() 第179行

修复2：庄家可以直接出牌
  问题：出牌检查要求手牌必须是14张，但庄家已经是14张
  修复：允许DEAL状态下庄家出牌
  影响：discardTile() 第263行

修复3：统一反应系统
  问题：单机模式和多人模式有不同的处理逻辑
  修复：统一使用initReactionSystem()
  影响：discardTile() 第287行

三、完整游戏流程示例
--------------------

场景：4人麻将，player0是庄家

第1轮（庄家出牌）：
1. 发牌：player0有14张，player1/2/3各有13张
2. player0出牌（不需要摸牌）
3. 检查反应：player1(下家)、player2(对家)、player3(上家)
4. 无人反应 → 推进到player1

第2轮（player1摸牌出牌）：
1. player1摸牌（13→14张）
2. player1出牌（14→13张）
3. 检查反应：player2(下家)、player3(对家)、player0(上家)
4. 无人反应 → 推进到player2

第3轮（player2摸牌出牌）：
1. player2摸牌（13→14张）
2. player2出牌（14→13张）
3. 检查反应
4. 假设player3可以碰牌：
   - player3碰牌
   - player3成为当前玩家
   - player3摸牌（从牌墙）
   - player3出牌
   - 继续游戏

四、特殊情况处理
----------------

1. 碰牌流程 ✓
   - 任何位置都可以碰
   - 碰牌后移除2张手牌
   - 碰牌者成为当前玩家
   - 碰牌者需要摸牌

2. 吃牌流程 ✓
   - 只有下家可以吃
   - 吃牌后移除2张手牌
   - 吃牌者成为当前玩家
   - 吃牌者需要摸牌

3. 杠牌流程 ✓
   - 明杠：别人打出，手中有3张
   - 暗杠：自己摸到第4张
   - 加杠：之前碰过，现在摸到第4张
   - 杠牌者成为当前玩家
   - 杠牌者需要从杠尾摸牌

4. 胡牌流程 ✓
   - 自摸：自己摸到的牌胡牌
   - 点炮：别人打出的牌胡牌
   - 胡牌后游戏立即结束
   - 胡牌优先级最高
